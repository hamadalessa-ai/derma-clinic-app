# Derma Clinic App (demo)

Arabic-first clinic management SaaS for dermatology & aesthetic clinics in Saudi Arabia.
**Demo only — fake patient data.** See `CLAUDE.md` for rules, `docs/ROADMAP.md` for phases and `docs/DEPLOY.md` to put it online.

## The link to use

Always open and share the **main production link**: `https://<your-project>.vercel.app`
(Vercel → your project → **Domains**, the first one). Signed-in admins also see it on the dashboard.
Don't share the long "deployment" links Vercel shows for each build — they are frozen snapshots.

- Staff: `/` (sign in)
- Patients — online booking: `/book`
- Patients — my appointments: `/my`
